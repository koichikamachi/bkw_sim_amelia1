## Excel 版に合わせる中身
1. 借越の上限：Excel 版にはないが、付けることにした（11-09）。画面では 0 なら上限なし。超えたら ValueError を出し、画面に表示する。
2. 使う／使わない：Excel 版は常に使う。切替を付けることにした（11-09）。既定は ON。
3. 利息：前月末の借越残高 × 年利 ÷ 12 を円で四捨五入（Excel の ROUND と同じ）し、当月に預金から払う。この支払いもその月の不足計算に含める（923・956 行）。
4. 科目名：Python 版の既存名（当座借越借入金・当座借越利息）を使う。
5. 月内の順番：その月の入出金をすべて記帳した後、月末に「借りる」か「返す」のどちらか一方（952・953 行）。
   - B ＝ 預金の前残 ＋ 当月の入金 − 当月の出金
   - B < 0 なら −B を借りる。B > 0 かつ借越前残 > 0 なら、min(B, 前残) を返す。
6. 出口：売却月に借越の前残を預金から全額返す。預金が足りない分は元入金で埋める（預金／元入金、863 行）。売却月は新たに借りない。シミュレーションは売却の年で終わる。
7. 税金の支払い（預金から）：
   - 所得税（法人税）：年末に計算し、翌年 2 月に払う（968 行）。売却の年の分は売却月に払う。
   - 消費税：年末に未払消費税を計上し、翌年 2 月に払う（764・765・785 行）。還付（未収還付消費税）も 2 月に受け取る。売却の年の分は売却月に払う。
   - Python 版の「未払を元入金へ振替」は、残高 0 を確かめる安全策として残す（通常は仕訳なし）。
8. 端数：利息は円で四捨五入。

## Excel 版の直す箇所・気になる点（見つかり次第追記）
1. 建物・追加設備の償却率が `ROUND(1/耐用年数, 3)`（75 行）。22 年なら 0.045 で、法定の定額法償却率 0.046 と違う。Python 版は 1/耐用年数（0.04545…）で、これも法定の表とは違う。どれに揃えるか要判断。
2. 売却月（12 月）に減価償却をしていない（建物・追加設備とも 11 か月分）。売却月まで償却するのが普通ではないか、要判断。Python 版は 12 か月分。
3. 千円単位で四捨五入する箇所が多い（返済額、償却額、利息など）。円単位の Python 版と ±1 千円程度ずれる。直す必要はないが、突き合わせのときの前提として記録。
4. 消費税の計算（756〜785 行）。Excel 版は税込経理で、月ごとの消費税を 763 行の式で計算する。
   - 売上側は家賃の全額（414 行）に税率を掛けている。課税割合は仕入側（販管費・売却費用）にだけ掛かる。家賃に非課税の住宅家賃が含まれるなら、売上側も課税分だけにすべきではないか。
   - 建物・追加設備の取得にかかる消費税は、計算に入っていない（仕入税額控除も還付も起きない）。Python 版は税抜経理で、取得時の仮払消費税を課税割合で控除し、還付が起きる。
   - 住宅用の賃貸建物は、2020 年 10 月以降の取得分から仕入税額控除が制限されている（居住用賃貸建物の取扱い）。どちらの扱いを正とするかは、税制の確認を含めて要判断。
   - 売却代金は簿価の比で建物・土地に分け、建物部分に消費税を掛けている（778 行）。Python 版は建物と土地の売却額を別々に入力する。
